# 来源推导

只有在确定输出画布和可写入的空白胶片区域之后，才能从已曝光照片中推导作品。默认保留来源图像的原始尺寸与宽高比；只有用户明确要求其他输出格式时才可改变，绝不能仅为制造可写空间而更改。可写区域限制作品的放置位置，但不决定视觉语法。

## 检视这张照片

用结构关系描述照片，而不是罗列物体。寻找大约 3–5 个真正能区别这张照片的特征，例如：

- 主导视觉体量或具有特征性的比例；
- 强烈的空间轴线或方向关系；
- 重复、节奏、分组或中断；
- 相对尺度以及前景／背景组织；
- 密集与空旷之间的对立；
- 几何结构与有机形态之间的对立；
- 光影组织；或
- 从来源中可见且重要的色彩里选取克制的子集。

不必使用每一个类别。优先选择少量、有清晰视觉证据的关系。“三个紧密排列的形态向纵深逐渐缩小”比仅仅说出三个物体的名称更有用。

## 选择具有区分度的关系

只有同时满足以下条件时，才保留一个候选关系：

1. 它在照片中有明确可见的依据；
2. 它对照片的身份或组织方式有实质贡献；
3. 它可以在不描绘物体、不延伸场景的情况下被转译；
4. 它比能够套用于许多无关照片的一般观察更具体。

记录每个入选关系的可见证据。不要推断未出现的事件、原因、后果、记忆或具体情绪叙事。当照片中有可见支持时，可以诠释视觉氛围、张力、节奏或感受。

## 推导抽象语法

针对每个入选关系：

1. 陈述可见证据。
2. 在不预先指定图形手段的前提下表达该关系。
3. 判断是否需要在抽象作品中表现它。
4. 然后才选择能够传达它的最小形式、尺度、间距、层级、色彩或材质行为。
5. 确认结果抽象的是关系，而不是描绘物体或延续场景。

使用以下链条：

> 可见证据 → 独特关系 → 抽象原则 → 最小图形表达

不要从圆形、矩形、网格、弧线、线条、半透明叠层、包豪斯式形式或其他流行手法开始。只有当这张照片本身能够证明其合理性时，才可以使用相应手段。

原始胶片灼痕边界可以影响作品能够出现的位置，但不能被当作需要呼应、延伸、描摹、平衡或装饰的母题。

## 检验来源特异性

请问：

> 基本相同的抽象构图，是否也可能由一张显著不同的照片生成？

如果答案是肯定的，找出并舍弃那些通用决定。回到可见证据，选择更有区分度的关系。只改变通用图形的颜色、标题或位置，并不会形成新的语法。

作为最后的字面化检查，应优先转译关系，而不是保留可辨认物体的轮廓。如果某个抽象元素会立刻被看成来源物体的简化图标，请检验能否在不损失来源特异性的前提下，用更不字面的方式表达同一关系。这里并不禁止可辨认的形式；来源特异性仍比为了抽象而抽象更重要。

不同照片应当产生实质不同的抽象系统。系列的一致性来自推导过程、保护规则与克制，而不是重复使用的母题。

## 推导可选的诗性文字

最多使用一条克制的编辑性短语，通常为 1–5 个词。优先使用片语而不是完整句子。当有强而可信的短语出现时，鼓励使用文字；如果无法令人信服地推导出来，则应省略。

短语可以回应照片的氛围、关系、构图、光线、空间、节奏、张力或被暗示的感受。它不必描述场景，也不必充当标题，并且不应只是说出可见物体的名称。

接受文字之前：

1. 找出支持该短语感受或概念的可见证据，或用户明确提供的陈述。
2. 拒绝对过去或未来事件、未见动作、原因、后果、记忆、地点、离开、返回、没有证据的天气或其他未见叙事作出具体断言。
3. 优先选择回应视觉关系、但不解释照片也不把照片简化成物体标签的语言。
4. 对语言也应用来源特异性测试：基本相同的短语是否可能合理地配在许多显著不同的照片旁？如果是，请从这张照片中推导出更具体的语言，或省略文字。
5. 避免在一个系列中形成反复出现的句法公式、诗性结构或短语模板。

当可见关系确实支持时，“held apart”“almost still”“small distances”或“quiet weight”等短语可以成立。“after the rain”“waiting for you”“the day we left”“coming home”或“last summer”等短语则需要用户明确提供相应背景。可以自由诠释关系，但绝不虚构事实。
