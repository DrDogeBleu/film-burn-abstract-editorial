# Film Burn Abstract Editorial

简体中文 | [English](README.md)

一个 Codex Skill：保留局部意外曝光的胶片画面，只在真正的空白胶片区域中创作由原照片关系推导出的抽象编辑艺术。

> **保留意外。在剩余的空白中抽象照片。**

## 关于

局部曝光的胶片可能同时包含三种材质意义不同的区域：已经曝光的照片、曝光停止处的意外边界，以及真正的空白胶片。本技能保护前两者，只把第三种区域视为可能的创作画布。

空白并不是需要修复、替换或自动填满的缺陷。技能会先阅读照片内部的比例、节奏、方向、密度、光线、色彩、间距与张力，再为现有空白胶片推导出克制的抽象回应。

**由照片决定作品，而不是让作品反过来支配照片。**

## 与常见做法的不同

这不是胶片灼痕生成器，也不是一套预设视觉风格。它从真实存在的胶片意外出发，并将其作为证据完整保留。每张照片都必须推导出自己的抽象语法，不能只是把可辨认物体简化成图标。

当照片确实支持时，技能可以加入一条极短的诗性文字。文字必须针对该照片、保持克制并处于次要位置，不能凭空制造事件或背景故事。

> **可以自由诠释关系，但绝不虚构事实。**

## 核心原则

| 区域 | 角色 |
|---|---|
| **已曝光照片** | 受保护的源内容 |
| **原始胶片灼痕／曝光边界** | 受保护的源内容 |
| **真正的空白／未曝光胶片** | 可写入的创作画布 |

- 默认保留原始像素尺寸、完整画面与宽高比。
- 不得仅为制造更多可写空间而裁切、拉伸或缩放。
- 不生成、修复、强化、清理或模仿胶片灼痕。
- 不把照片中的场景延伸或重建到空白区域。
- 每张照片都应产生不同的抽象系统。
- 适当时让大部分可写胶片继续作为负空间存在。
- 只有在出现可信且有可见依据的短语时才使用文字。

## 工作方式

1. 区分已曝光照片、原始曝光边界和真正的空白胶片。
2. 如果无法可靠识别具有实际意义的可写区域，则停止。
3. 锁定并保护照片与边界。
4. 选出少量真正区别于其他照片的视觉关系。
5. 将这些关系转译为最少量、针对该来源的抽象语法。
6. 可选：从照片可见的氛围或结构中推导一条极短的诗性片语。
7. 只在真正的空白胶片内合成生成元素。
8. 检查来源完整性、负空间和创意特异性。

完整的操作行为由 [SKILL.md](SKILL.md) 及其英文参考文件定义。

## 使用

附加一张局部曝光的胶片扫描图，或把它放入项目，然后直接调用：

```text
Use $film-burn-abstract-editorial on this partially exposed film scan.
```

无需重复技能中已经包含的详细创意与保护规则。

## 适合的输入照片

理想输入应包含：

- 具有实际内容的已曝光照片；
- 可以辨认的原始曝光边界；
- 足以容纳克制干预的真正空白或未曝光胶片。

空白区域可以位于照片上方、下方、左侧、右侧，或以不规则形状围绕照片。竖幅与横幅都适用。

## 技能会拒绝什么

遇到以下情况时，工作流程应停止，而不是继续：

- 在没有可靠可写区域的完整曝光照片上绘制；
- 凭空制造空白胶片或胶片灼痕边界；
- 修复、重新设计、戏剧化或装饰这次意外；
- 把景物、物体、光线或透视延伸到空白胶片；
- 接受与来源无关的通用图形或重复使用的短语公式；
- 在工作流程无法验证时声称像素完全一致。

## 局限

- 是否符合条件以及可写区域如何划分，取决于能否从输入扫描图中可靠判断。
- 这是一个纯指令型技能；只有实际采用的生成与合成流程执行并报告验证时，才能保证受保护像素完全不变。
- 生成结果可能需要迭代，才能同时通过来源完整性与创意特异性检查。
